# 🏥 Healthcare Analytics Dashboard – Power BI

## 📌 Project Overview

This project is a Healthcare Analytics Dashboard developed using Microsoft Power BI to analyze healthcare data and gain insights into patients, hospital admissions, medical conditions, billing amounts, insurance providers, medications, and test results.

The dashboard contains interactive visualizations, KPI cards, filters, and navigation buttons that help users explore healthcare information and identify patterns in the dataset.

## 🎯 Objectives

- Analyze patient demographics and medical conditions.
- Understand hospital admission patterns.
- Compare hospital performance and average length of stay.
- Analyze healthcare billing and insurance information.
- Explore medication usage and medical test results.
- Create interactive dashboards for data-driven insights.
